# 육아 정리함 — 자체 주소 판 올리기

Claude 공개 링크 화면은 외부 지도·위치 권한·외부 API·유튜브 플레이어를 막습니다. 그래서 병원·약국 탭의 **앱 안 지도와 '지금 문 연 곳' 목록**, 영상 탭의 **앱 안 재생**은 자체 주소 판에서만 동작합니다.

## 구성

| 부분 | 하는 일 |
|---|---|
| `build.py` | 앱을 빌드합니다. 공개 링크용 `app.html`, 로컬 미리보기용 `index.html`, 자체 주소 판 `site/index.html`을 만듭니다. 빌드 전에 브랜드 정책 검사를 합니다 |
| `fetch_clinics.py` | 국립중앙의료원 공공데이터에서 소아청소년과·약국·달빛어린이병원 목록과 요일별 진료 시각을 받습니다. 0.1도 격자 칸마다 나눠 `site/data/clinics/`에 씁니다 |
| `.github/workflows/deploy.yml` | GitHub Actions가 매일 03:00(한국 시간)에 위의 두 단계를 실행하고, GitHub Pages에 배포합니다 |

- **위치:** 보호자가 '내 위치로 가까운 곳 보기'를 누를 때만 씁니다. 내 위치 칸과 둘레 8칸의 자료만 받아 기기 안에서 거리를 잽니다. 위치를 서버로 보내지 않습니다.
- **지도:** 카카오맵입니다. 지도를 그리려면 카카오에 지도 영역을 요청하게 됩니다.
- **길찾기:** 길찾기만 카카오맵으로 넘어갑니다.

## 해야 할 일(직접 하셔야 하는 단계)

키 발급과 가입은 본인이 직접 해야 합니다. 키 값은 코드나 채팅에 붙이지 말고, 아래 '저장소 비밀 값'에만 넣어 주세요.

1. **개인 GitHub 계정에 새 저장소를 만듭니다.** 회사 계정이나 회사 저장소는 쓰지 않습니다.
   - GitHub 무료 계정에서 Pages를 쓰려면 저장소가 공개여야 합니다.
2. **이 폴더의 파일을 저장소 맨 위에 올립니다.**
   - 올릴 파일: `app.template.html`, `build.py`, `brand_check.py`, `fetch_clinics.py`, `catalog.json`, `deals_checked.json`, `who_growth.json`, `.github/`, `.gitignore`
   - `site/`와 `.keys/`는 올리지 않습니다(`.gitignore`가 막습니다).
3. **공공데이터포털(data.go.kr)에서 인증키를 받습니다.**
   - 회원가입 후 다음 두 API에 활용신청을 합니다(자동 승인).
     - 국립중앙의료원_전국 병·의원 찾기 서비스
     - 국립중앙의료원_전국 약국 정보 조회 서비스
   - 마이페이지의 **일반 인증키(Decoding)** 를 저장소 비밀 값 `DATA_GO_KR_KEY`로 넣습니다. 위치는 Settings → Secrets and variables → Actions입니다.
4. **카카오 개발자(developers.kakao.com)에서 JavaScript 키를 받습니다.**
   - 앱을 만들고 **카카오맵 사용 설정을 ON**으로 바꿉니다.
   - JavaScript SDK 도메인에 Pages 주소(`https://계정이름.github.io`)를 등록합니다.
   - **JavaScript 키**를 저장소 비밀 값 `KAKAO_JS_KEY`로 넣습니다.
   - 카카오맵 무료 쿼터는 개발자 계정당 처음 카카오맵을 켠 앱 하나에만 줍니다.
5. **Pages 배포 방식을 정합니다.** Settings → Pages → Source를 **GitHub Actions**로 바꿉니다.
6. **배포를 실행합니다.** Actions → '육아 정리함 배포' → Run workflow를 누르고, 끝나면 `https://계정이름.github.io/저장소이름/`을 엽니다.
7. **첫 배포를 확인한 뒤 처리방침에 위치·카카오맵·공공데이터 내용을 넣고**, 그다음에 다른 사람에게 주소를 알려 줍니다.

## 첫 배포 뒤 확인할 것

- Actions 기록의 '병원·약국 자료 받기' 단계에서 소아청소년과·약국·달빛어린이병원 건수를 봅니다.
- '달빛어린이병원 목록을 받지 못했습니다'가 나오면 오퍼레이션 이름이 다른 것입니다.
  - 공공데이터포털 명세서에서 이름을 확인해 `fetch_clinics.py`의 `OPS['moon']`을 고칩니다.
  - 고치기 전까지는 진료 안내 글에 '달빛'이 적힌 곳만 표시됩니다.
- 진료과목 코드 D002가 소아청소년과인지 확인합니다. 받은 목록 몇 곳의 이름과 진료과목을 보고 판단합니다.
  - 이 코드는 이용 사례로 확인한 값이라 명세서와 대조가 필요합니다.
- 휴대폰으로 병원·약국 탭을 열고 '내 위치로 가까운 곳 보기' → 위치 허용 → 지도와 목록이 뜨는지 봅니다.

## 내 컴퓨터에서 시험하기

1. `.keys/data_go_kr.txt`와 `.keys/kakao_js_key.txt`에 키를 한 줄씩 넣습니다.
2. 다음 명령을 차례로 실행합니다.
   - `python3 build.py`
   - `python3 fetch_clinics.py`
   - `python3 -m http.server 8000 -d site`
3. `http://localhost:8000`을 엽니다. 카카오 JavaScript SDK 도메인에 `http://localhost:8000`도 등록해야 지도가 뜹니다.
